# Mathemagicia

Мистическая математическая игра-головоломка для детей 6–10 лет в алхимическом стиле.

## О проекте

Mathemagicia — интерактивная игра, где каждый уровень — это магическая математическая задача. Шесть глав, каждая со своим типом головоломки:

- **I — Граф связей** — проведи цепочку через узлы так, чтобы сумма чисел равнялась цели
- **II — Магический квадрат** — расставь числа 1–9 в сетке 3×3 так, чтобы суммы по строкам, столбцам и диагоналям равнялись 15
- **III — Тёмные звёзды** — найди все безопасные звёзды, не задев тёмные (в стиле «сапёра»)
- **IV — Нонограмма** — закрась клетки по числовым подсказкам и проявь скрытый рисунок
- **V — Magic Stars** — расставь числа 1–10 в узлы пятиконечной звезды так, чтобы сумма по каждому лучу равнялась 22
- **VI — Хитори** — зачеркни числа по правилам: без повторов в ряду, зачёркнутые клетки не касаются

Прогресс бесконечный — каждые 6 уровней открывают новое реальное созвездие из каталога IAU (88 созвездий). Все открытые созвездия собираются в коллекцию «Небо открытий».

Игра доступна на русском и английском языках.

## Стек

- **React 18** (UMD, без бандлера)
- **Babel Standalone** (JSX прямо в браузере)
- **SVG-анимации**, CSS-переходы
- **Capacitor** — упаковка в нативный Android APK
- **Web Audio API** — звуковой движок с записями челесты

## Запуск

### Веб-версия (браузер)

Открой `www/index.html` в браузере — никакой сборки не требуется.

Для разработки с дизайн-инструментами (макеты, iOS-frame) — открой `MathGame/index.html`.

### Сборка Android APK

```bash
# 1. Скопировать веб-файлы в Android assets
npx cap copy android

# 2. Собрать debug-APK (нужен Android Studio JDK)
cd android
./gradlew assembleDebug
```

Готовый APK будет в `android/app/build/outputs/apk/debug/app-debug.apk`.

## Структура

```
MathGame/          — рабочая копия для разработки (с DesignCanvas)
  prototype.jsx      оркестратор экранов + GameShell
  screens.jsx        экраны: обложка, выбор глав, победа, настройки, коллекция созвездий
  atoms.jsx          переиспользуемые компоненты + переводы + SFX/MUSIC движки
  puzzles.jsx        головоломки глав I (граф) и III (тёмные звёзды)
  puzzles-2.jsx      головоломки глав II, IV, V, VI
  graph-gen.js       генератор уровней (xorshift PRNG)
  constellations-data.js  база 88 реальных IAU созвездий
  audio/             записи челесты (sound, tap, place, win)

www/               — продакшн-копия для APK и веб-версии
                     (те же JSX + app.jsx для чистого запуска игры)

android/           — Android-проект Capacitor
                     собирается через gradlew в APK

generate-icons.js  — генератор Android иконок из icon.png
capacitor.config.json — настройки Capacitor
```

## Звук и музыка

- **Фоновая музыка** играет на обложке, экране выбора глав и в коллекции созвездий (челеста, зацикленная)
- **SFX** для тапов, установки фигур и победы записаны на реальной челесте
- Останавливается при входе в игру, возобновляется при выходе
- Автопауза при сворачивании приложения
- Отдельные слайдеры для звуков, музыки и вибрации в настройках

## Иконки приложения

Иконка приложения — стилизованное созвездие «M» на звёздном фоне.
Для регенерации всех размеров:

```bash
node generate-icons.js
```
